## 🚀 Featured Project

### 💬 QuickChat – Real-Time Messaging Application

<a href="https://github.com/sahilans3/QuickChat">
  <img src="https://img.shields.io/badge/GitHub-View_Project-181717?style=for-the-badge&logo=github" />
</a>
<a href="https://quickchat-sable.vercel.app">
  <img src="https://img.shields.io/badge/Live-Demo-00C853?style=for-the-badge&logo=vercel&logoColor=white" />
</a>

A full-stack real-time messaging application that enables users to communicate instantly through a responsive chat interface.

**Key Features:**
- 🔐 Secure authentication using JWT and bcrypt.
- ⚡ Real-time messaging using Socket.IO.
- 🟢 Live user presence and active user tracking.
- 💬 One-to-one instant messaging with chat history.
- 👤 User profiles and Cloudinary image uploads.
- 📱 Responsive UI for desktop and mobile devices.
- 🏗️ MVC-based backend architecture and REST APIs.

**Tech Stack:** React.js, Vite, Node.js, Express.js, MongoDB, Mongoose, Socket.IO, Zustand, Cloudinary.
